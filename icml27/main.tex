\begin{abstract}
  We present a synthetic task testing Witness-Gated Associative Recall, specifically
  designed to test learning an arbitrary hypergraph.  The task is deterministic, sports
  inexhaustible combinatorial variety, and is unhackable as far as we know.  The only
  way a transformer can perfectly solve it is to learn the correct mechanism.
\end{abstract}
